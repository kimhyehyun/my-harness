# ChriFit PRD — 오늘 할 운동을 고르고, 체크하고, 기록하는 앱

> 근거: Figma `ChriFit Design System` (02 Screens, 03 Harness) · 디자인 기준: docs/design.md
> 이전 허들링 PRD는 docs/prd-huddling.md에 보관한다.
> 이 문서는 Figma 화면에 보이는 것만 근거로 썼다. 근거가 없는 항목은 §9 "확인 필요"에 모았다.

## 1. 한 줄 요약
내가 헬스장에서 혼자 운동할 때 쓰는 **개인용 앱**이다. 오늘 할 운동을 고르고
하나씩 체크하며 진행한 뒤, 시간·칼로리·PT 받은 날을 기록으로 남긴다.

## 2. 사용자
사용자는 **나 한 명**이다. 여러 사람이 쓰는 앱이 아니다.

| 상황 | 필요한 것 | 화면 근거 |
|---|---|---|
| 헬스장에서 혼자 운동한다. 오늘 뭘 할지 매번 고민한다 | 직접 고르기 / 스마트 랜덤 | 오늘 |
| 가끔 PT를 받는다. PT 받은 날을 따로 표시해 두고 싶다 | PT 받은 날 토글, PT 배지 | 오늘의 운동, 기록 |

## 6. 기능 요구사항
### 6-1. 오늘
- 오늘 날짜와 날씨를 보여준다
- 진행 중인 운동이 있으면 "오늘 운동 이어서 하기"와 완료 수(n/m)를 보여준다
- 운동 고르는 방법 2가지: 직접 고르기(목록에서 선택), 스마트 랜덤(앱이 골라줌)
- 선택한 개수를 보여주고, 확인을 누르면 오늘의 운동을 시작한다

### 6-2. 운동 목록 · 운동 추가
- 운동 이름 검색
- 필터: 즐겨찾기(전체/즐겨찾기), 부위, 기구
- 운동마다 이름, 부위, 기구, 썸네일, 즐겨찾기
- 내 운동 만들기
- 시트에서는 여러 개를 골라 한 번에 추가한다

### 6-3. 오늘의 운동
- 진행률(완료 n / 전체 m, %)
- 운동마다 체크, 설명 보기, 빼기
- 운동 추가
- 오늘 기록: 운동 시간(분), 칼로리(kcal), PT 받은 날
- 칼로리는 Apple Watch와 연동해 가져온다 (§6-7)
- 오늘 운동 마치기, 체크 전부 지우기

### 6-4. 운동 설명
- 운동 이미지, 부위·기구 태그, 동작 단계, 포인트
- 기본 세트 × 횟수
- 오늘 운동에 담기, 즐겨찾기

### 6-5. 운동 완료
- 운동 시간, 칼로리, 완료 수
- 완료한 운동 목록
- PT 받은 날 표시
- 기록 보기, 오늘 화면으로

### 6-6. 기록
- 이번 달 운동 횟수, 총 시간·칼로리·PT 횟수
- 주간 달력 (운동한 날 표시)
- 날짜별 기록 카드: 날짜, 오늘·PT 배지, 계획(시간·컨디션·세트×횟수), 운동 칩, 시간·kcal, PT 받은 날, 삭제

### 6-7. Apple Watch 연동 (칼로리)
- 칼로리(kcal)는 Apple Watch에서 측정한 값을 가져와 채운다 (iOS 건강 앱/HealthKit 경유)
- 값의 출처가 Apple Watch임을 화면에 표시한다
- 워치 데이터는 칼로리 칸만 채운다. 운동 체크(완료)는 바꾸지 않는다 → §8 규칙 1

## 7. 데이터 (화면에 보이는 필드만)
### Exercise
| 필드 | 설명 |
|---|---|
| name | 운동 이름 |
| part | 부위 (가슴·등·어깨·하체·힙·코어·전신) |
| equipment | 기구 (맨몸·덤벨·바벨·머신·케이블) |
| image | 운동 이미지 |
| source | 출처 (§8 규칙 2) |
| favorite | 즐겨찾기 |
| default_sets, default_reps | 기본 세트 × 횟수 |
| steps, tip | 동작 단계, 포인트 |
| custom | 내 운동 여부 |

### DayRecord
| 필드 | 설명 |
|---|---|
| date | 날짜 |
| items[] | 운동과 상태 (`미완료` / `완료`) |
| minutes | 운동 시간 |
| kcal | 칼로리 (Apple Watch에서 가져옴) |
| kcal_source | `apple_watch` (연동 값) |
| pt | PT 받은 날 |
| condition | 컨디션 |

운동 상태는 `미완료` / `완료` 두 가지뿐이다. `완료`는 사용자 체크로만 바뀐다.

## 8. 어기면 안 되는 것
1. 운동 기록은 사용자가 직접 체크한 것만 남긴다. 자동으로 완료 처리하지 않는다.
2. 운동 이름·설명·이미지는 출처를 표시하고, 허락된 자료만 쓴다.

## 9. 확인 필요 (화면에 근거 없음)
- 스마트 랜덤이 운동을 고르는 기준
- 컨디션(보통·100%) 입력 방법
- Apple Watch가 없거나 연동하지 않은 사용자의 칼로리 처리 (직접 입력 허용 여부)
- 운동 시간(분)도 Apple Watch에서 가져올지 여부
- 건강 데이터 접근 권한을 거부했을 때의 화면
- "내 운동 만들기" 화면 구성
- 데이터 저장 위치 (기기 / 서버)
- 운동 이미지 사용 허락 (현재 fitnessprogramer.com 이미지는 시안용)

## 10. 범위 밖
로그인·회원가입·다른 사용자 계정 (나 혼자 쓰는 앱), 결제·구독, 커뮤니티·피드·채팅·랭킹·공유, 태블릿·데스크톱, 라이트 테마
