## 완료 기준 (한 문장)
선택한 플로우의 핵심 화면이 Figma에 너비 390(최소 높이 844)으로 그려졌고,
쓰인 토큰과 컴포넌트가 design.md 위반 0건으로 검사를 통과했으며,
사람이 컨펌을 1회 했다.

## "위반 0건"이 세는 것 (기준: docs/design.md = ChriFit, 숫자는 rules.json)
1. 색: 모든 fill/stroke가 ChriFit color 변수에 바인딩됨 (변수 없는 색 0개)
2. radius: 0 / 1.5 / 3 / 4.5 / 6 / 9 / 12 / 18 / 24 / 999만 허용
3. 텍스트: 모든 글자에 ChriFit 텍스트 스타일 연결 (스타일 없는 글자 0개)
4. drop shadow: 0개
5. Primary 버튼: 화면당 1개 이하
